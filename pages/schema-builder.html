Данные разметки

Поля со звёздочкой * обязательны для выбранного типа.

JSON-LD


              
    
              
    
                Разметка помогает поисковым системам понять страницу, но не гарантирует появление расширенных результатов.
                Дополнительно проверить код можно в валидаторе validator.schema.org.
              
    
            
    
          
    
        
    

        
    
          
    Как пользоваться
    
          
    
            
    
              
    Шаги
    
              
      
                
    1. Выберите тип схемы и заполните поля — код обновляется сразу.
      2. 
                
    2. Исправьте замечания проверки: обязательные поля, формат URL, дат и чисел.
      3. 
                
    3. Скопируйте код и вставьте его в HTML страницы (в <head> или <body>).
      4. 
              
    
            
    
            
    
              
    Важно
    
              
      
                
    • Указывайте только данные, которые есть на странице и соответствуют действительности.
      • 
                
    • Даты — в формате ГГГГ-ММ-ДД, ссылки — полные, с https://.
      • 
                
    • Пустые поля в код не попадают.
