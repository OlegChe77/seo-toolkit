Семантическое ядро — это список поисковых запросов, по которым сайт должен находиться в поиске, разложенный по страницам. От него зависит структура сайта, тексты, метатеги и то, какие страницы вы будете создавать в первую очередь. Ниже — рабочая схема сбора ядра без платных сервисов: за вечер можно собрать ядро для небольшого сайта или раздела.

## Что понадобится

- 3–5 «маркерных» фраз — коротких запросов, которые описывают ваш товар, услугу или тему: «купить диван», «перетяжка мебели», «ремонт ноутбуков».
- [Keyword Finder](/keyword-finder) — подбор расширений запроса с примерной частотностью.
- [IntentFinder](/intent-finder) — разделение запросов по намерению пользователя.
- [KeyCluster](/key-cluster) — группировка запросов по страницам.

Все три инструмента связаны: результат одного передаётся в следующий одной кнопкой, без копирования и вставки.

## Шаг 1. Найдите маркерные запросы

Маркер — это то, как ваш продукт называют сами пользователи. Выпишите основные товары или услуги и сформулируйте их двумя-тремя словами, без брендов и городов: «диван кровать», «угловой диван», «кухонный диван». Смотрите на меню сайта, названия категорий у конкурентов и формулировки в отзывах клиентов.

Не берите слишком общие слова вроде «мебель»: по ним придёт много запросов, которые не относятся к вашему бизнесу.

## Шаг 2. Расширьте маркеры в Keyword Finder

Вставьте маркеры в [Keyword Finder](/keyword-finder) — по одному в строке — и запустите поиск. Инструмент соберёт подсказки поисковых систем по каждому маркеру, оценит частотность и сложность и подсветит фразы цветом:

- **зелёные** — заметный спрос и невысокая конкуренция, с них выгодно начинать;
- **жёлтые** — средние по сложности;
- **красные** — самые конкурентные, для молодого сайта это долгая дорога.

Частотность в Keyword Finder — оценка по подсказкам, а не данные счётчика поисковой системы. Если у вас есть точные цифры из Вордстата хотя бы для нескольких фраз, воспользуйтесь калибровкой: так оценки станут ближе к реальности.

## Шаг 3. Почистите список

Прежде чем разбирать ядро, уберите мусор:

- запросы с чужими брендами и маркетплейсами («диван на авито»), если вы не продаёте на этих площадках;
- услуги и товары, которых у вас нет («диван бу», если вы продаёте только новые);
- регионы, где вы не работаете;
- явно нерелевантные фразы, которые попали из подсказок.

В Keyword Finder удобно фильтровать по цвету, классу частотности и словам: кнопки передачи берут только отфильтрованные фразы.

## Шаг 4. Разделите запросы по интенту

Нажмите «Определить интент в IntentFinder». Инструмент разделит запросы на информационные, коммерческие, транзакционные и навигационные. Это важно, потому что под разные намерения нужны разные страницы:

| Интент | Пример | Какая страница |
| --- | --- | --- |
| Транзакционный | купить угловой диван | категория каталога, карточка товара |
| Коммерческий | лучшие диваны для сна | подборка, сравнение, обзор |
| Информационный | как выбрать диван | статья, гайд |
| Навигационный | икеа диваны | обычно не продвигается |

Запросы, в которых намерение неочевидно, IntentFinder помечает для ручной проверки — просмотрите их и при необходимости поменяйте категорию. Подробнее — в гайде [«Интент поискового запроса»](/guides/intent-zaprosa).

## Шаг 5. Разложите запросы по страницам

Нажмите «Разбить на кластеры в KeyCluster». Инструмент сгруппирует запросы по общим словам и не станет смешивать разные интенты. Каждый кластер — кандидат в отдельную страницу:

1. Главный (самый частотный) запрос кластера — основа для Title и H1.
2. Остальные запросы кластера — для подзаголовков, текста и описаний.
3. Суммарная частотность кластера помогает понять, какие страницы делать первыми.

Одиночные запросы проверьте вручную: часть можно добавить к подходящим кластерам, часть — оставить для отдельных статей.

## Шаг 6. Сохраните и передайте результат

Выгрузите кластеры в CSV — файл откроется в Excel с кириллицей. Если над сайтом работает команда, нажмите «Поделиться»: получится ссылка, по которой коллега откроет тот же результат. Данные хранятся в самой ссылке и не загружаются на сервер.

## Частые ошибки

- **Собирать ядро без маркеров.** Без чёткого списка товаров и услуг ядро разрастается до тысяч нерелевантных фраз.
- **Сажать разные интенты на одну страницу.** «Купить диван» и «как выбрать диван» лучше продвигать разными страницами.
- **Гнаться только за высокочастотными запросами.** Молодому сайту проще получить трафик по среднечастотным и низкочастотным запросам.
- **Не обновлять ядро.** Спрос меняется: раз в несколько месяцев повторяйте сбор для ключевых разделов.
